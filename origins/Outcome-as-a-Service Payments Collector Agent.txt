1. The "Labeling" Technique (Chris Voss Style)
Instead of "Where is my money?", the agent uses tactical labeling.
* The Script: "It seems like there might be a mismatch between the project's internal approval and the finance department’s current schedule. Is there a specific hurdle I can help clear to make this easier for your team?"
* The Result: This removes the "accusatory" tone and positions the agent as a collaborator, not a bill collector.
2. The "Loss Aversion" Pivot
Large companies often have "Early Payment Discounts" they ignore. The agent flips this.
* The Script: "I noticed the original terms included a 2% net-30 discount which has now lapsed. I’d hate for your department to lose that budget efficiency. If we can settle this by Friday, I’m authorized to honor the original discounted rate as a one-time courtesy."
* The Psychology: Humans hate losing a "deal" more than they like paying a bill.
3. The "Human-in-the-Loop" Illusion
The agent builds rapport by "deflecting" the pressure to a fictional third party.
* The Script: "My accounting lead is asking for an update for the end-of-month audit. I’d love to tell them we’re all set so they don't have to flag this. Could you let me know if the wire is initiated?"
* The Psychology: This makes the agent an "ally" against the "cold corporate accounting department," triggering a social desire to help the "friendly" agent.

The Codat Integration Logic
The following script targets the GET /companies/{companyId}/data/invoices endpoint. It uses a query string to isolate invoices where the status is "Open" and the due date has already passed.


Python




import requests
import datetime

# Configuration
CODAT_API_KEY = "YOUR_CODAT_API_KEY"
BASE_URL = "https://api.codat.io"
COMPANY_ID = "CLIENT_COMPANY_ID_FROM_CODAT" # The SME's unique ID

def get_overdue_invoices(company_id):
   # Calculate "today" for the query filter
   today = datetime.date.today().isoformat()
   
   # Codat Query Language (CQL) filter: 
   # Status is 'Open' AND the Due Date is before today
   query_filter = f"status=Open&&dueDate<{today}"
   
   url = f"{BASE_URL}/companies/{company_id}/data/invoices"
   headers = {
       "Authorization": f"Basic {CODAT_API_KEY}",
       "Content-Type": "application/json"
   }
   params = {
       "query": query_filter,
       "pageSize": 50
   }

   try:
       response = requests.get(url, headers=headers, params=params)
       response.raise_for_status()
       data = response.json()
       
       overdue_list = data.get("results", [])
       return overdue_list

   except requests.exceptions.RequestException as e:
       print(f"Error fetching data from Codat: {e}")
       return []

# Execute
invoices = get_overdue_invoices(COMPANY_ID)

for inv in invoices:
   customer_name = inv.get('customerRef', {}).get('companyName', 'Unknown')
   amount_due = inv.get('totalAmount', 0)
   days_overdue = (datetime.date.today() - datetime.date.fromisoformat(inv['dueDate'][:10])).days
   
   print(f"ALARM: {customer_name} owes ${amount_due}. Invoice is {days_overdue} days late.")

* The Connection Flow: Your SMEs won't give you their password. You will send them a Codat Link URL. They click it, log into their Xero/QuickBooks, and Codat securely hands you the token.
